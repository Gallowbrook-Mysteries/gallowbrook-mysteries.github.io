# Gallowbrook Mysteries

The companion site for the Gallowbrook puzzle mysteries by Chris Blakeney: answer checks, clarifications and news.

Static site, served by GitHub Pages from the root of this repository. Pages are generated by a build script kept with the book files; edit the content there, not here.

Answer checks run entirely in the reader's browser. Answers are stored only as salted SHA-256 hashes, and each case's epilogue is AES-GCM encrypted with a key derived (PBKDF2) from the correct answer.
